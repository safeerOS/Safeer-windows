# Safeer OS za Windows 1.0.29

- **Medijski center: glasba brez naslova nad vsako kartico.** V mreži Glasba je bil nad skoraj vsako skladbo svoj naslov z imenom izvajalca, zato je bila stran razvlečena in težko pregledna. Skupine po izvajalcu se zdaj pokažejo samo, kadar ima izvajalec v povprečju vsaj dve skladbi; sicer je glasba ena pregledna mreža.
- **Safeer Link ne kopiči več niti v ozadju.** Vsako iskanje središča Safeer Link v omrežju je za sabo pustilo eno nit; po mnogih urah delovanja jih je bilo na tisoče. Iskanje zdaj za sabo pospravi.

English: the Music grid in the Media Center no longer puts an artist heading above almost every track – artist groups appear only when an artist has at least two tracks on average. Safeer Link no longer accumulates background threads (every search for a hub on the network used to leave one behind).
