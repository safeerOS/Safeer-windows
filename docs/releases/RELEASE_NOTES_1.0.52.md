# Safeer OS za Windows 1.0.52

- **Safeer Player:** samo Medijski center v svojem oknu, s svojim namestitvenim programom (SafeerPlayer-setup.exe).
- **Zaščita računa IPTV:** v ozadju se seznami z računom ne odpirajo, naenkrat ena prijava na račun, vir z geslom nikoli »brez računa«, o potrditvi vira odloča ta naprava.
- **Skupna koda iz Safeer Linux 1.0.133:** ožji krog za ključe in vire, ključ storitve ne gre napravam zunaj ožjega kroga, stabilnost.
- **Gradnja:** predvajalnik libmpv s pripetim, preverjenim runtime MSVC; preverba utrjenosti vseh programov v paketu.
