# Safeer OS za Windows 1.0.44

**Spletne strani ne zaznajo več, da ima Safeer vgrajen blokator oglasov.** Ena splošna zaščita, enaka za vse strani (brez pravil za posamezne): preverjanja z vabnimi elementi, lažnimi zahtevami proti oglasnim strežnikom in preizkusnimi skriptami dobijo enak odgovor kot brez blokatorja, zato se sporočilo »izklopite blokator oglasov« ne pojavi.

Prazni vabni elementi (npr. »adsbox«) ostanejo v strani, skriti s CSS. Blokiranje oglasov in groženj deluje kot prej; YouTube je izvzet.
