# Safeer OS za Windows 1.0.46

**Strani ne zaznajo več blokatorja, tudi ko oglasno knjižnico zamenjajo.** Nekatere strani (npr. internetni radio liveone.com) so med nalaganjem zamenjale oglasno knjižnico Google (`googletag`) z novo in po nekaj sekundah sklepale, da je blokirana. Splošna zaščita (ista za vse strani) zdaj tudi novo knjižnico prikaže kot pripravljeno. Preverjeno na pravi strani: prej ena zaznava, zdaj nobena. Blokiranje oglasov in groženj ostaja nespremenjeno; YouTube je izvzet.
