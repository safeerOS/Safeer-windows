# Safeer OS za Windows 1.0.45

**Strožja zaščita pred zaznavanjem blokatorja.** Nekatere strani (npr. internetni radio) so še pokazale »zaznali smo blokator oglasov«. Splošna zaščita (ista za vse strani, brez pravil za posamezne) zdaj odgovori tudi na preverbe, ki so jih prej zgrešile: skriti vabni elementi javijo običajen položaj (tudi `offsetParent`), sledilne slikice se naložijo, oglasna knjižnica Google (`googletag`) je videti pripravljena, seznam oglasnih in sledilnih naslovov je razširjen. Blokiranje oglasov in groženj ostaja nespremenjeno; YouTube je izvzet.

Popravljeni so tudi preizkusi na Windows (kodiranje datotek UTF-8).
