# Safeer OS za Windows 1.0.5

Prva javna izdaja Safeer OS za Windows – isti Safeer OS kot na televizorju, tablici, telefonu in Linuxu, v enem oknu.

- **Stranska vrstica kot povsod:** Domov, Medijski center, Safeer Link, Programi, Datoteke, Splet, Zapiski, Nastavitve.
- **Pametno iskanje v zgornji vrstici:** spletni naslov ali vprašanje odpre Splet, datoteke Datoteke, programi Programe, filmi in glasba Medijski center – tudi po imenu spletne aplikacije.
- **Splet ostane v Safeer OS:** zavihki, +, nazaj/naprej, osveži, domov, naslovna vrstica, priljubljene, ščit – brez zunanjega brskalnika.
- **Safeer Link:** računalnik je polnopravna naprava v krogu zaupanja (povezava s QR ali 6-mestno kodo). Programe drugih naprav vidiš s pravimi ikonami in jih zaženeš tu: program z Linux računalnika se odpre na ločenem zaslonu in ga upravljaš z miško in tipkovnico Windows; igre se odprejo čez cel zaslon.
- **Medijski center:** filmi z Internet Archive, PeerTube, radio, podkasti, TV v živo (uradni prenosi), lastni viri in uradni »Kje gledati« po državi.
- **En primerek:** ponoven zagon pripelje obstoječe okno v ospredje.
- **Prvi zagon:** če na računalniku ni Pythona, ga Safeer OS po vprašanju namesti sam (uradni paket prek winget), nato namesti potrebne knjižnice.

English: First public release of Safeer OS for Windows – the same side bar as on every Safeer device, smart search, the web inside Safeer OS, Safeer Link as a full peer (programs of other devices with their icons; a Linux program opens on its own screen and is controlled with the Windows keyboard and mouse, games full screen), Media center with legal sources, single instance, and automatic Python setup on first start.
