# Safeer OS za Windows 1.0.35

- **Gumbi po več urah delovanja ne obnemijo več.** Safeer OS vmesnik občasno naloži znova, da sprosti pomnilnik. Po takem nalaganju je vmesnik ostal brez povezave z aplikacijo: »Išči« v razdelku Splet, odgovor na vprašanje o novi napravi in vsi drugi gumbi niso naredili nič, dokler nisi Safeer OS zaprl in znova odprl. Povezava se zdaj vzpostavi ob vsakem nalaganju. Če je kdaj vseeno ni, jo Safeer OS doda sam in vmesnik nanjo počaka; če ne gre niti tako, to pove, namesto da gumbi molčijo.
- **Vmesnik se ne naloži znova sredi dela.** Dokler predvajaš, pišeš ali je odprto vprašanje, Safeer OS s sproščanjem pomnilnika počaka.
- **Desni klik v polju: Izreži, Kopiraj, Prilepi, Izberi vse – v jeziku vmesnika.** Prej se je odprl angleški meni brskalnika z »Back«, »Reload« in »View page source«, ki v Safeer OS ne sodi. Če odložišče besedila ne sprejme ali ga ne vrne, Safeer OS to pove.
- **Novo različico lahko namestiš, ko je Safeer OS še odprt.** Če si prenesen `SafeerOS-Windows-….exe` zagnal ob odprtem (tudi pomanjšanem) Safeer OS, se je namestitev ustavila z »Napaka pri pripravi datotek … being used by another process« in pustila napol posodobljene datoteke. Zdaj se posodobitev izvede, nova različica pa sama prevzame od stare.
- **Ukaze aplikaciji sprejme Safeer OS samo od svojega vmesnika.** Spletna vsebina v vgrajenem predvajalniku jih ne more poslati.
- **Krajevna knjižnica:** film v mapi ali z imenom, ki vsebuje črki »tv« (na primer »Latvia«), ni več razvrščen med serije.
- Opozorila Qt se zapisujejo v dnevnik `safeer_os.log`.

English: **Buttons no longer go dead after hours of use.** Safeer OS reloads its interface from time to time to free memory; after such a reload the interface was left without its connection to the app, so Search in the Web section, the answer to the new-device question and every other button did nothing until Safeer OS was closed and opened again. The connection is now set up on every load; if it is ever missing, Safeer OS adds it itself and the interface waits for it, and if even that fails it says so instead of staying silent. **The interface is not reloaded in the middle of something** – while you are playing, typing or a question is open, freeing memory waits. **Right-click in a field: Cut, Copy, Paste, Select all in the interface language** instead of the browser's English menu with Back, Reload and View page source; if the clipboard does not accept or return the text, Safeer OS says so. **A new version can be installed while Safeer OS is still open** – running a downloaded `SafeerOS-Windows-….exe` while Safeer OS was open (even minimised) used to stop with "being used by another process" and leave half-updated files; the update now goes through and the new version takes over from the old one by itself. **Safeer OS accepts commands only from its own interface** – web content in the embedded player cannot send them. **Local library:** a film in a folder or with a name containing the letters "tv" (for example "Latvia") is no longer filed under series. Qt warnings are written to `safeer_os.log`.
