# Safeer OS za Windows 1.0.13

- **Krog zaupanja se pospravi sam:** naprava, ki je ni bilo 90 dni (npr. stara identiteta telefona po ponovni namestitvi), gre iz kroga; umik je podpisan in velja na vseh napravah. Sorodne identitete žive naprave ostanejo (telefon, njegov brskalnik in predvajalnik so ena naprava), ugasnjeno središče nikogar ne odstrani – pospravlja šele po eni uri delovanja in le, če je krog nedavno videlo. Enako kot Safeer Control za Linux in Safeer OS za Android.

English: The trust circle tidies itself – a device unseen for 90 days (e.g. a phone's old identity after reinstall) is removed with a signed revocation that applies on all devices; sibling identities of live devices stay and a hub that was switched off does not remove anyone. Same behaviour as Safeer Control for Linux and Safeer OS for Android.
