# Safeer OS za Windows 1.0.21

- **Bližnjice na začetni strani Spleta so tvoje:** »Uredi bližnjice« (ali desni klik) → odstraniš katerokoli, tudi vgrajeno; »Obnovi privzete« jih vrne. Nič ni vsiljeno.
- **Nastavitve si zapomni:** izbrana tema, skrita ali skrčena stranska vrstica, izbira podnapisov, napredek glasbe in »Ne zdaj« pri novi napravi so se po vsakem ponovnem zagonu izgubili (vmesnik je vsakič tekel na drugih lokalnih vratih). Zdaj ostanejo.
- **Vprašanje »Nova naprava v Safeer Linku«** se po »Ne zdaj« ne vrača več ob vsakem zagonu in je prevedeno v vse jezike vmesnika.
- Pasica »Na voljo: Safeer OS …« na domačem zaslonu te pripelje naravnost do gumba Posodobitve.
- Nastavitve: izbirnik vrste medijskega strežnika je v temi, prazen razdelek »Hitre nastavitve« se ne kaže več.

English: start-page shortcuts can be removed (built-in ones too) and restored; preferences kept in the interface (theme, sidebar, subtitles, "Not now" for a new device) now survive a restart; the new-device question is translated; the home banner jumps straight to the Updates button.
