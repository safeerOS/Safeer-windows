# Safeer OS za Windows 1.0.10

- **Predvajalnik na libmpv:** Medijski center in samostojni Safeer Predvajalnik uporabljata lastno LGPL gradnjo libmpv (AV1, HEVC, DASH/HLS z izbiro kakovosti, strojno dekodiranje d3d11va). Nadaljuj tam, kjer si končal; poglavja, skok na čas, hitrost, zamik podnapisov in zvoka, posnetek slike.
- **Sistemske medijske kontrole (SMTC):** medijske tipke delujejo tudi brez fokusa okna; ploščica ob glasnosti, zaklenjen zaslon in slušalke vidijo naslov in stanje.
- **Stremio dodatki:** brskanje po katalogih in predvajanje tokov iz tvojih dodatkov (Ctrl+B v predvajalniku; v Medijskem centru kot dodatne različice).
- **Sporočila – skupni nabiralnik:** mape Prejeto/Neprebrano/Poslano, kanali, iskanje in filtri; pogovor s panojem osebe (naslovi, datoteke).
- **Sporočila – osebe in oznake:** osebo poimenuješ po svoje, združiš njene račune z več kanalov (e-pošta + klepet) ali jih razdružiš; oznake pogovorov s filtrom; iskanje po sporočilih ene osebe.
- **Dodaj kanal:** izbereš ponudnika (Gmail, Siol, T-2, Telemach, Amis, Arnes, Yahoo, iCloud, GMX, mail.com, Zoho, Fastmail, Posteo, Seznam …), vpišeš le naslov in geslo, navodila so zraven; zavihek *Aplikacije* za ponudnike brez IMAP; zavihek *Lastni API* (Matrix, Telegram Bot).
- **Teme:** Nastavitve › Videz – poleg privzete Safeer še Catppuccin, Tokyo Night, Gruvbox, Nord in Dracula.
- **Safeer Link:** če na istem računalniku že teče Safeer Hub, se drugi ne zažene več (dva Huba z istim imenom sta druge naprave zmedla – povezava je bila zavrnjena).
- **Link daljinec** upravlja Medijski center (play/pause/stop/naprej/nazaj); skrita stranska vrstica tudi v spletnem načinu.

English: Media Center and the standalone Safeer Player now run on our own LGPL libmpv build (AV1, HEVC, DASH/HLS quality selection, hardware decoding); resume where you left off, chapters, jump to time, speed, subtitle/audio delay, snapshot. Windows system media controls (media keys without window focus, lock screen, headphones). Stremio add-ons for browsing and playing streams. Messages: unified inbox with folders, channels, search and filters; people you can rename, merge across channels or split; conversation labels; search within a person's messages; "Add channel" with a provider picker (address + password only), an Apps tab and an Own API tab (Matrix, Telegram Bot). Themes: Catppuccin, Tokyo Night, Gruvbox, Nord and Dracula next to the default Safeer look. Link remote controls the Media Center. A second Safeer Hub on the same computer no longer starts (two hubs with the same name confused other devices).
